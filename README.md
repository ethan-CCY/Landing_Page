# Mayasalu 水彩畫廊

Mayasalu 線上畫廊是為水彩藝術家打造的個人網站，聚焦於作品展示、畫風介紹與來訪資訊，並支援行動裝置瀏覽。

## Demo

- https://ethan-CCY.github.io/Landing_Page/

## 功能列表

- Hero 首屏與藝術家簡介
- 線上畫廊作品卡片、分類篩選與 Lightbox 放大檢視
- 實體畫廊資訊與 Google Maps 快捷開啟
- 聯絡表單與替代聯絡方式提示
- 針對手機與平板優化的響應式版面
