# Mayasalu 水彩畫廊

Mayasalu 是水彩藝術家個人線上畫廊的展示網站，主打透明層疊與留白的清爽視覺，並提供作品分類、放大檢視與聯絡表單。

## Demo

https://ethan-CCY.github.io/Landing_Page/

## 功能列表

- 水彩藝術家個人品牌與畫風介紹
- 線上畫廊作品網格、分類篩選與 Lightbox 放大檢視
- 實體畫廊資訊與 Google 地圖導引
- 前端驗證的聯絡表單與替代聯絡方式
- RWD 版面支援手機與平板
